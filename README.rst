Описание
-----------
Менеджер для работы с Mongo

Установка пакетом
-----------
Для локальной разработки::
    pip install -e packages/mongo_manager

Импорт
-----------
Проверка::
    from managers.mongo_manager import MongoManager


Удаление
-----------
Удалить пакет::
    pip uninstall mongo_manager

Для создания пакета
https://docs.python.org/3.10/distutils/introduction.html#distutils-simple-example
https://docs.python.org/3.10/distutils/sourcedist.html
::
    python setup.py sdist
